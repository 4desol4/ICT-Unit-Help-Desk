❓ COMMON ISSUES QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

"ict.local not found"
  → Restart PC
  → Verify Bonjour installed
  → Or use IP: http://192.168.1.50:3000

"Port already in use"
  → Check what's using it: netstat -ano | findstr :5000
  → Kill it: taskkill /PID <PID> /F
  → Or change PORT in backend/.env

"Cannot connect to PostgreSQL"
  → Check PostgreSQL is running: services.msc
  → Verify credentials in backend/.env
  → Test: psql -U ict_local_user -d ict_support_local

"Auto-start not working"
  → Run: setup-autostart.ps1 as Administrator
  → Check Task Scheduler: Win+R → taskschd.msc
  → Look for "ICT Support Desk - Auto-Start"

"Sync not working"
  → Check backend/.env has SYNC_ENABLED=true
  → Verify both DATABASE_URL and NEON_DATABASE_URL exist
  → Watch backend window for [DBSync] messages
  → Restart backend if needed
