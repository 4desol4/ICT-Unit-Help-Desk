PROBLEM: ict.local doesn't work
SOLUTION: Use IP instead: http://192.168.1.50:5173

PROBLEM: Other PC can't see app
SOLUTION: 
  1. Both on same Wi-Fi? ✓
  2. Use correct IP (not 127.0.0.1 or localhost)
  3. Check firewall allows ports 5000 and 5173

PROBLEM: Database sync not working
SOLUTION:
  1. Check backend/.env has NEON_DATABASE_URL
  2. Verify internet connection
  3. Look at backend console for errors

PROBLEM: Setup script fails
SOLUTION:
  1. Run PowerShell as Administrator
  2. Verify Node.js and PostgreSQL installed
  3. Check versions: node --version, psql --version
